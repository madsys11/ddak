# 앱 아이콘 교체 (2026-10-26)

**요청**: 설치된 앱 아이콘은 Tauri 기본 로고였다. 시안 15종과 G·K·L 변형 9종 가운데 사용자가 G(쌍디귿 ㄸ) 원래 시안을 골랐다.

**구현**:
- 원본 `src-tauri/app-icon.svg`: ㄷ 두 개(민트·노랑, 두 세션). macOS 아이콘 격자(1024 안에 824 몸체, 모서리 185)와 그림자.
- `npx tauri icon src-tauri/app-icon.svg`(tauri-cli 2.12.4)로 `src-tauri/icons`를 다시 만들었다. 함께 생기는 `android/`·`ios/`·
  `64x64.png`는 설정(`tauri.conf.json` icon)에서 쓰지 않아 지웠다.

**만들며 고친 것**: 처음에는 몸체에 `feDropShadow`를 걸었는데, 생성된 1024px PNG의 바탕에 가로 줄무늬가 보였다. PNG를 직접
디코드해 한 열을 보니 R이 22→13으로 계단처럼 떨어졌다. 필터 입력이 기본 linearRGB 8비트를 거치며 어두운 색의 정밀도를 잃은 것
(headless Chrome으로 그려도 같았다). 그림자는 따로 그린 검은 rect에만 blur(`color-interpolation-filters="sRGB"`)를 걸고 몸체는
필터 없이 그리게 바꿨다. 다시 디코드하니 60px마다 1~3씩 매끄럽게 변하고 모서리 알파 0, 그림자 알파 31.

**확인**: cargo test 87 통과, 전체 selftest PASS 391 / FAIL 0. icns를 `iconutil`로 풀어 16~1024 크기가 모두 있음.
