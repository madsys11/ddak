# 고정폭 글꼴 D2Coding

대상: 기준 b21a274, 커밋하지 않은 변경 (`src/monoFont.ts`, `src/assets/fonts/`, `src/main.tsx`, `src/Terminal.tsx`, `src/App.css`,
`src/selftest.ts`, `scripts/selftest-plan.json`, `docs/spec.md`).

## 배경

사용자 요청: Windows와 맥에서 모두 가독성이 좋은 한글·영어 글꼴. 사용자 결정: D2Coding.
전에는 `Menlo, monospace`라 Windows에서는 다른 글꼴로 대체되어 두 OS의 모양이 달랐다.

## 계획 리뷰

### R4 (P2) `document.fonts.check`로는 글꼴을 찾았는지 알 수 없다

판단: 타당. CSS Font Loading 규격의 check는 맞는 면이 없으면 true다. 대체 글꼴로 잰 폭 비교도 같이 통과할 수 있다.

수정: `@font-face` 대신 `monoFont.ts`에서 FontFace 두 개(400·700)를 만들어 등록하고, 테스트가 그 객체의 등록·`loaded` 상태를
직접 본다. PC에 설치된 D2Coding이 실패를 가리지 않는다.

### 라이선스 (지적)

판단: 타당. OFL FAQ 2.2는 형식 변환(WOFF 등)이 수정판이 아니려면 압축 외 원본 데이터와 메타데이터가 그대로여야 한다고 한다.
예약 이름은 D2Coding·D2Coding-Bold.

수정: woff2 대신 배포된 원본 TTF를 그대로 넣는다 (sha256이 릴리스 zip의 파일과 같음). 저작권·라이선스는 TTF의 name 표에 있다
(0: Copyright NAVER, 13: SIL OFL 1.1, 14: openfontlicense.org. 직접 읽어 확인). `OFL.txt`는 공개 저장소의 소스 배포용으로 같은 폴더에 둔다.

## 확인

- `terminalFont` 통과: 두 면 loaded, 칸 폭 6 = floor(6.5 × 1.5)/1.5 (화면 비율 1.5), 한글 13 = 영문 6.5 × 2 (보통·굵게).
- 실패 확인: 등록하지 않으면 `unloaded:false`, 주소가 틀리면 `error:true`로 세 검사 모두 실패하고, 앱은 대체 글꼴로 뜬다
  (터미널 준비 단계 통과, 대체 글꼴의 W 폭은 7).
- 첫 화면 지연: 글꼴 불러오기 약 67ms (개발 빌드, 두 번 잼).
- 크기 (Windows 릴리스): ddak.exe 7.1MB → 10.8MB, NSIS 설치 파일 2.3MB → 5.9MB (Tauri가 앱 파일을 압축해 넣는다).
- 맥과 전체 자체 테스트는 돌리지 못했다 (Windows에서 selftest.sh가 돌지 않음).
- 리뷰 요청에 따라 `terminalContrast`를 새 글꼴로 다시 돌림: 통과 (가장 진한 픽셀 rgb(95,104,104), 5.31:1), 대비 설정을 끄면
  실패 (rgb(147,161,161), 2.48:1). 글꼴을 바꿔도 테스트가 갈린다.

## 구현 리뷰

글꼴 변경에는 차단 지적 없음.

### R5 (P2) 재설치 스크립트가 설치 실패를 알리지 않는다

대상: 저장소 밖의 Windows 재설치 스크립트 (Claude 세션 임시 폴더의 `reinstall.ps1`. ddak 밖에서 NSIS 설치 파일을 `/S`로 돌린다).

지적: setup이 세 번 모두 실패해도 그대로 앱을 띄우고 실패 코드를 내지 않아, 구버전이 떠서 적용 여부를 오판한다. 실패하면
앱 실행을 건너뛰라는 제안.

판단: 일부 타당. 실패를 기록하지 않고 결과를 확인하지 않는 것은 결함이다. 하지만 실패하면 ddak를 띄우지 않는 것은 받지 않는다.
작업 세션(개발·리뷰)이 모두 ddak 안에서 돌아서, 띄우지 않으면 사용자에게 아무것도 남지 않고 실패를 알려 줄 세션도 없다.

수정: 설치 뒤 설치된 ddak.exe와 이번 빌드의 ddak.exe를 SHA256으로 비교해 `RESULT OK|FAIL setup=<코드> same-as-build=<참/거짓>`을
기록한다. 실패해도 ddak는 다시 띄우되 스크립트는 종료 코드 1로 끝난다. 재설치 뒤에는 이 RESULT 줄로 적용 여부를 확인해 보고한다.
한글 주석 때문에 PowerShell 5.1이 읽도록 UTF-8 BOM을 붙였다 (실행하지 않고 문법 검사만 함).
