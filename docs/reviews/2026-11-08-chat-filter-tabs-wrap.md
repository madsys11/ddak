# 채팅 작업그룹 탭이 넘치면 다음 줄로 (2026-11-08)

## 요청 (사용자)

채팅창 위의 작업그룹 탭이 5개 이상부터 잘려서 안 보인다.

## 판단

- 탭 줄은 넘치면 가로로 밀리게 되어 있고 스크롤바는 숨겼다 (`App.css` `.chat-filter-tabs`: `overflow-x: auto`,
  `scrollbar-width: none`. 2026-11-05 `chat-filter-tabs`). 맥 트랙패드는 가로로 밀 수 있지만, Windows 마우스 휠은 세로로만
  밀어서 넘친 탭에 닿을 방법이 없다. 스크롤바도 없어서 넘쳤다는 표시도 없다.
- 실험 (Windows, 패널 폭 341px, 그룹 11개): 수정 전에는 `dev-review-4`부터 8개 탭이 탭 묶음 밖에 있었다
  (scrollWidth 864 / clientWidth 324, 높이 26px 한 줄). 사용자가 말한 증상과 같다.
- 고르는 방법: 줄 바꾸기. 탭이 모두 한눈에 보이고, 입력 장치와 상관없다. 휠을 가로로 바꾸는 방법은 넘친 것이 보이지 않는
  문제가 남는다. 그룹이 많으면 줄이 늘지만, 작업그룹을 수십 개 열 일은 없다.
- 폰(`mobile.css`)은 손가락으로 가로로 밀 수 있어서 그대로 둔다.

## 수정

- `src/App.css`
  - `.chat-filter-tabs`: `flex-wrap: wrap`. 가로 스크롤과 스크롤바 숨기기는 뺀다.
  - `flex: 1 1 0; min-width: 120px`: basis가 auto면 탭 전체 길이가 기준이라 묶음이 한 줄을 다 차지하고 토글이 다음 줄로
    밀린다. basis 0으로 남는 폭을 모두 차지하게 해서 "나에게 온 것만" 토글은 오른쪽 끝에 남는다. 남는 폭이 120px보다 좁으면
    숨긴 수가 다음 줄로 내려간다 (바깥 `.chat-filter`는 원래 `flex-wrap: wrap`).
  - `.chat-filter-tab`: `max-width: 100%`와 말줄임. 이름 하나가 패널 폭보다 길 때만 쓰인다.
- `docs/spec.md` 채팅 필터 모양, `src/ChatFilterBar.tsx` 주석.

## 리뷰 1회 (origin/reviewer, #133)

- R13 · P2 — 탭 묶음 높이가 무제한이라 본문·입력란을 밀어냄: **타당**.
  - 근거: `src/chatFilter.ts` groupsIn은 지금 참여자뿐 아니라 받은 메시지에 관계된 모든 그룹을 탭으로 만든다. 그래서 탭은 지난
    작업그룹까지 쌓이고, "수십 개 열 일은 없다"는 판단은 틀렸다. `.chat-filter`는 `flex: none`이고 본문 `.chat-list`는
    `flex: 1; min-height: 0`이라 탭 묶음이 커지면 본문이 먼저 줄어든다.
  - 실험: 높이 제한 없이 탭 34개(패널 341×780)면 묶음 높이 396px, 본문 179px.
  - 수정: `.chat-filter-tabs`에 `max-height: 80px`(탭 높이 26.4px의 세 줄), `overflow-y: auto`, `overflow-x: hidden`.
    넘치면 세로 스크롤바가 보이고 휠로 밀 수 있다. `.chat-members`(76px)·`.chat-paused-list`(104px)와 같은 방식이다.
  - 확인: 검사를 그룹 30개(탭 34개)로 늘리고, 묶음이 세 줄 이하이고 세로로 넘치는지, 끝까지 밀면 마지막 탭이 묶음 안에 보이는지,
    본문이 100px보다 높은지, 입력란이 패널 안인지 본다. 수정하면 통과 (높이 80, scrollHeight 422, 본문 495px, 입력란 아래 772 / 패널
    780). `max-height`만 빼면 실패 (높이 396, 본문 179px).
- R14 · P3 — 말줄임 뒤 긴 이름을 볼 수 없음: **타당**. 탭 안내(`title`)가 모든 탭에 같은 문구였다.
  - 수정: `chat.filterGroupHint`에 `{group}`을 넣어 "dev-review-30: …"으로 (en·ko).
  - 확인: 검사 "작업그룹 탭 안내에 그룹 이름 전체" 통과.
- 남은 한계: 고른 탭이 넷째 줄 이후에 있으면 다시 열었을 때 고른 탭이 보이지 않는 위치일 수 있다 (탭 묶음 맨 위가 보인다).
