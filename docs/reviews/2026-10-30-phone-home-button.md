# 폰 채팅에 처음(컴퓨터 목록)으로 가는 버튼 (2026-10-30)

**요청** (사용자): 컴퓨터를 여럿 쓰게 되어, 설정 아이콘처럼 홈으로 가는 아이콘이 필요하다. 여러 프로젝트를 다닌 뒤 뒤로 가기로
컴퓨터 선택까지 가기가 번거롭다.

**지금 동작**: 채팅의 ‹는 프로젝트 목록(`#/c/<id>`), 프로젝트 목록의 ‹는 (컴퓨터가 여럿이면) 컴퓨터 목록(`#/`)으로 간다.
화면 이동은 모두 주소 기록에 쌓이므로, 폰의 뒤로 가기로는 다닌 프로젝트를 모두 거슬러 가야 한다.

**수정** (`src/mobile/MobileApp.tsx`)
- `HomeButton`: 막대 오른쪽 버튼(`bar-side`, ⚙과 같은 모양)에 집 아이콘(SVG, `currentColor`라 테마 글자색을 따른다).
  누르면 `#/`(컴퓨터 목록). 접근성 이름은 컴퓨터 목록 제목과 같은 `phone.computers`를 다시 쓴다 (새 문구 없음).
- 채팅 화면에만, 컴퓨터가 여럿일 때만 (`Chat`의 `home`). 프로젝트 목록의 ‹가 이미 컴퓨터 목록으로 가고,
  컴퓨터가 하나면 `#/`가 그 프로젝트 목록으로 넘어가 ‹와 같다.
- `mobile.css`: 막대 버튼 안의 SVG를 블록으로 가운데 둔다 (글자 기준선 아래 빈칸이 생기지 않게).
- spec "모바일 연결"의 폰 화면 항목에 적음.

  누르면 주소가 `#/`. 버튼을 빼면 이 검사가 실패한다 (`true undefined `).
