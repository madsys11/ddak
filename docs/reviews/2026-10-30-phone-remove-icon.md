# 폰 컴퓨터 목록의 빼기 버튼을 작은 빨간 아이콘으로 (2026-10-30)

**요청** (사용자): 컴퓨터 선택 화면의 Remove(빼기) 버튼을 실수로 누르기 쉽다. 빨간 계열로, 크기가 너무 크니 아이콘 형태로.

**지금 동작**: `ComputerList`의 줄 오른쪽 `row-side` 버튼에 글자 "빼기"/"Remove". 기본 버튼 모양(배경·테두리 채움)이라 눈에 띄고 크다.
누르면 `confirm`으로 확인 창을 띄우고 확인해야 뺀다 (이 동작은 그대로 둔다).

**수정**
- `src/mobile/MobileApp.tsx`: 글자 대신 휴지통 선 아이콘. 접근성 이름·title은 기존 `phone.remove` (새 문구 없음).
  집 버튼과 같은 SVG 속성을 `Icon`으로 묶었다. 시험에서 그리도록 `ComputerList`를 내보낸다.
- `src/mobile/mobile.css` `.row-remove`: 배경·테두리 없이 `--error`색 (테마마다 이미 작은 글자 대비를 맞춘 토큰), 아이콘 20px × 글자 배율,
  안쪽 여백 10px (누르는 칸 약 40px).
- spec "모바일 연결"의 폰 화면 항목에 적음.

**확인**
- tsc 통과, `npm run build:mobile` 통과.
- 자체 테스트 `mobileThemeUnit`에 검사 2개:
  - 모든 테마에서 빼기 버튼이 배경 없이 `--error`색.
  - 실제 `ComputerList`를 그려: 글자 없는 SVG 아이콘(이름 "빼기"), 확인 창 문구, 취소하면 빼지 않고 확인하면 뺀다.
- 대조: 아이콘을 글자로 되돌리고 `.row-remove`의 색·배경을 빼면 두 검사 모두 실패한다
  (dark에서 글자색 rgb(204, 204, 204)·배경 rgb(49, 49, 49), 아이콘 검사 `false 빼기`).
- 전체 `scripts/selftest.sh`: 다섯 시나리오 모두 통과, PASS 529, FAIL 0.
